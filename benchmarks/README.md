# Benchmark Results

Results coming soon. No measured benchmark runs have been published yet.

This page will collect device/model comparisons and links to individual run reports. Planned initial devices are the Mac mini M4 with 64 GB RAM and MacBook Air M2 with 16 GB RAM.

## Run Reports

Reports will be grouped by device and run date under [`runs/`](runs/):

```text
runs/<device-id>/<run-id>/
  results.json
  report.md
```

Each report will include hardware and runtime settings, single-request and sequential-batch results, resource measurements, and reasons for skipped or failed models. See the [benchmark methodology](../architecture/benchmarking.md) for the output and publication contract.
